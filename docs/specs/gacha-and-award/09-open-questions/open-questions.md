# 未決定

**決まっていないものは実装しない。** 器だけ作り、確定したら設定値を変える。

## 解決済み

### Q-1. 1ライン = 何枚 / 上限は何枚か → **1ライン 1枚・上限 4枚**（2026-08-27 確定）

`coins_per_line = 1`, `max_coins = 4`, `bonus_coins = 0` を既定値とする（G-11）。
去年の Flask 実装（`max_coins = 4`）と同じ。設定テーブルにあるため、
当日の状況を見て運営が変更できる。

### Q-2. スタッフ立会いをアプリで担保するか → **立会いは無い。アプリ内で完結**（2026-08-27 確定）

PIN も QR も作らない（G-10）。そのぶん誤操作防止を UI 側で厚くする（G-12）。

## 残っているもの

### Q-3. アワード投票

本仕様の対象外。コインとはデータも UI も独立させる。着手判断は別途。

### Q-4. 景品の在庫がなくなったときの扱い

運営が `is_enabled = 0` にしてガチャ全体を止める。景品単位の管理はしない（G-7）。

### Q-5. 景品の受け渡し方法（アプリ外）

立会いが無い以上、**参加者が自分でガチャポン筐体を回す**運用になる。
アプリの責務は「コインを1枚消費したことの記録」までで変わらないが、
筐体の設置場所・回し方の掲示は運営側の準備物。**アプリの実装には影響しない。**
