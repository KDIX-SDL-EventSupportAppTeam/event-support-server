# ガチャコインとアワード投票

**今年も使うが、後から追加する。** 本ディレクトリは
「後から足せる状態を保つための制約」を記録することが目的である。

## 現状

| 機能 | 状態 |
|---|---|
| ガチャ（`/gachapon`・`/gachapon/use`・`/gachapon/complete`） | 画面はあるが、**旧 Flask API を呼んでおり動かない** |
| アワード投票（`/award-vote`） | 同上 |

`src/shared/api/legacyParticipant.ts` 経由で `/api/bingo-status` `/api/use-gachapon-coin`
`/api/awards` `/api/votes/update` などを呼んでいるが、Fastify 側に実装は無い。

## 今回やること

1. **ビンゴからコインの概念を外す**（[bingo D-5](../bingo-dynamic-unlock/01-concept/decisions.md)）
   - `calcCoinsEarned()` をビンゴのライブラリから削除する
   - ビンゴカード API は `coins` を返さず `lines_completed` を返す
2. **ガチャ用の器だけ用意する**
   - `gacha_coin_uses` テーブル
   - `GET /events/:id/gacha/coins` / `POST /events/:id/gacha/coins/use`
3. **UI は「準備中」表示にする**（既存の `LegacyPlaceholderPage` を使う）
4. **旧 Flask を呼ぶコードを削除する**

## 絶対に守る依存の向き

```
ガチャ  ──参照──▶  ビンゴ（成立ライン数）
ビンゴ  ──✕──▶  ガチャ
```

**ビンゴはガチャコインを知らない。** ビンゴが計算するのは成立ライン数までで、
ライン数からコイン枚数への換算はガチャ側の責務。

これを守れば、ガチャの実装は**ビンゴを一切触らない独立した機能追加**になる。

## 中途半端に残さない

**旧 Flask を呼ぶコードは残さず消す。** 中途半端に残っていると
「動くはずなのに動かない」画面が生まれ、当日の混乱の元になる。
消しておけば、後から新 API で作り直すときに迷わない。
