# 実機リハーサル手順（ガチャ部分）

ビンゴのリハーサル（研究室メンバー10人規模）に**相乗りする**。単独では実施しない。
ビンゴを一周してライン成立まで到達した人が、そのままガチャまで進む。

## 事前準備

1. 運営画面で `is_enabled = 1`、`coins_per_line` / `max_coins` を本番設定にする
2. 実物のガチャポン筐体（または代替）を用意する。**スタッフ役は付けない**（G-10）
3. 参加者役のスマホは**実機**。ブラウザの開発者ツールに頼らない

## 観察の主眼

立会いを廃した（G-10）ため、リハーサルの主眼は**参加者がひとりで完結できるか**に移る。
実施者は口を出さず、参加者役が迷った箇所を黙って記録する。

## 手順

| # | 操作 | 確認すること |
|---|---|---|
| 1 | ライン0の状態でホームを見る | コインボタンが 0 枚・無効 |
| 2 | ビンゴを1ライン成立させる | ホームの枚数が増える（リロードなしで増えなくてよい。**増えないことを許容と決めたか確認**） |
| 3 | `/gachapon` を開く | 「一度使うと戻せない」が読める。**スタッフを探す文言が無い** |
| 4 | `/gachapon/use` を開く | 枚数が正しい |
| 5 | 「使用する」を**素早く2回**押す | 減るのは1枚。完了画面に進む |
| 6 | 完了画面を見る | 何枚目・何時何分・残り何枚が読める。**戻るで使用確認画面に戻れない** |
| 7 | 自分でガチャポンを回す | **誰にも聞かずに完結できたか**（アプリ外だが最重要の観察点） |
| 8 | ホームに戻る | 枚数が1枚減っている |
| 9 | 機内モードにして「使用する」 | エラーが出る。復帰後に再試行して**2枚減っていない** |
| 10 | 残高0で `/gachapon/use` | 「コインがありません」が出て、**使用ボタンが表示されない** |
| 11 | 運営が `is_enabled = 0` にする | 参加者側が「準備中」になる |
| 12 | 運営が `bonus_coins` を +1 | 参加者側の枚数が1増える |

## 記録すること

- 各操作の所要時間と、**途中で人に聞きたくなった瞬間**（立会いが無いため、ここが詰まると当日詰まる）
- 参加者が迷った箇所（言葉・ボタンの位置）
- `gacha_coin_uses` の全行をダンプし、`coin_index` に重複・欠番が無いことを SQL で確認
- 発生した不具合は `docs/tests/runs/` に記録する
