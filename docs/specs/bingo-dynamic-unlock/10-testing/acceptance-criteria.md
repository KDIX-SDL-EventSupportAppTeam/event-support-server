# 合格基準

**「テストする」ではなく、判定条件まで書き切る。**
実装が終わったらこのチェックリストを上から順に埋める。

## カード発行

- [ ] `bingo_cells` が正確に16行、`position` は 0..15 が1つずつ
- [ ] `zone='CENTER'` が4行で `position` は {5, 6, 9, 10}
- [ ] `is_achieved = 1` の行が **0行**（参加ボーナスは存在しない）
- [ ] アンケート回答済み: `is_revealed = 1` がちょうど1行、position 5、`source='PRESURVEY'`
- [ ] アンケート未回答: `is_revealed = 1` が **0行**。それでもカード生成は成功する
- [ ] 同一ユーザーで `ensureCard` を並行実行してもカードは1枚

## 解放

- [ ] 中央2マス目の達成で、対応するペアの外周2マスだけが `is_revealed = 1` になる
- [ ] **対応しない外周10マスは `is_revealed = 0` のままである**
- [ ] 中央3マス目の達成で、新たに2組が成立し**4マス**が開放される
- [ ] 中央4マス目の達成で、新たに3組が成立し**6マス**が開放される
- [ ] 累計で外周12マス、重複なし・欠落なし
- [ ] 中央マスの埋まり順65通りすべてで上記が成立する
- [ ] **外周マスの達成では解放が一切起きない**
- [ ] 同じペアで解放処理を並行に2回走らせても `card_unlock_events` は1行だけ
- [ ] 解放が2秒以内に完了する

## 推薦

- [ ] 推薦サービスが 500 を返しても解放が成功し、マスが埋まる
- [ ] 推薦サービスがタイムアウトしても解放が成功する
- [ ] `RECOMMENDER_URL` 未設定のまま結合テストが通る
- [ ] 推薦結果に既訪問・カード掲載済み・`is_active=0` のブースが含まれない
- [ ] `recommendation_scores` に候補全件が入る
- [ ] `was_assigned = 1` の件数が、その解放で開放されたマス数と一致する
- [ ] フォールバックの訪問者数集計にスタッフのチェックインが含まれない
- [ ] 決定表 29/30 件、179/180 件の境界でフェーズが切り替わる

## 情報漏れ（最重要）

- [ ] **カード取得 API が `is_revealed = false` のマスの `booth` を必ず `null` で返す**
- [ ] 同マスの `reason` も返さない
- [ ] 解放前に外周マスの `booth_id` が API レスポンスのどこにも現れない

## ライン

- [ ] 中央4マスすべて達成でライン数が **0**
- [ ] 中央2 + 同一ラインの外周2 で **1**（**4件の訪問でビンゴ1本**）
- [ ] 16マス達成で **10**
- [ ] ビンゴカード API が `coins` を返さない

## チェックイン

- [ ] 事前推薦マスのブースへ訪問すると、そのマスが達成になる（中央の空きを消費しない）
- [ ] 解放済みの外周マスのブースへ訪問すると達成になり、解放は起きない
- [ ] カード外訪問が `cell_id = NULL` で記録される
- [ ] カード外訪問でも `pending_rating` の対象になる
- [ ] 同じブースへの2回目のチェックインが 409 になる

## 評価

- [ ] 未評価のチェックインがあるとき `pending_rating` が返る
- [ ] 今まさに作ったチェックイン自身は `pending_rating` にならない
- [ ] `rating` が 0 または 5 のとき 422 になる（`RATING_SCALE=4`）
- [ ] 同じ `checkin_id` への2回目の評価が 409 になる
- [ ] `booth_ratings.scale` に 4 が入る
- [ ] 空白のみのコメントが `NULL` に正規化される

## 自己修復

- [ ] 解放イベントだけ作ってマスを未開放にした状態でカードを取得すると修復される
- [ ] **3回ぶんの解放イベントすべてが点検される**
- [ ] 修復時にも `recommendation_scores` が記録される

## フロント

- [ ] 推薦欄（`CheckInRecommendView`）が存在しない
