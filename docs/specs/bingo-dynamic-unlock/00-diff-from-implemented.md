# 現状の実装との差分

**この文書は移行用である。実装が完了したら [archive/](../../archive/) へ移す。**

既に `integration/2026-08-bingo-staged-unlock` ブランチに「中央4マス完成 → 外周12マス一括解放」
方式の実装がある。旧仕様は
[archive/2026-08-bingo-staged-unlock/](../../archive/2026-08-bingo-staged-unlock/) にある。

## 一言でいうと

**「1回で12マス開く」から「2マス揃うたびに、その列の2マスを開く（最大3回）」へ。**

## 差分一覧

| # | 論点 | 現状の実装 | 新仕様 | 影響 |
|---|---|---|---|---|
| A | 初期1マス | `SIGNUP_BONUS`。中央1マスを**達成済み**で配る | **廃止。** position 5 に事前アンケート由来の推薦ブースを**見えるが未訪問**で配る | 大 |
| B | 解放トリガ | 中央4マス完成で**1回だけ** | 中央2マス揃うたび。**最大3回**（2/4/6マス） | 特大 |
| C | 解放範囲 | 外周12マス一括 | ペアが成すビンゴ列の外周2マス | 特大 |
| D | 推薦呼び出し | 1回・12件 | 3回・2件/4件/6件。除外リストは累積 | 大 |
| E | 推薦度の保持 | `cell_assignment_logs.score`（マスに載った分のみ） | `recommendation_scores`（**全候補**・凍結値つき） | 大 |
| F | マスの状態 | `state ENUM('LOCKED','EMPTY','ACHIEVED')` | `is_revealed` / `is_achieved` の**2軸に分解** | 大 |
| G | カードの段階 | `bingo_cards.status` の2値 ENUM | **保存しない。** マスから導出し、履歴は `card_unlock_events` | 大 |
| H | 評価段階数 | `RATING_SCALE` 既定 3 | 既定 **4**（中央なし星4段階） | 小 |
| I | 評価 UI | 評価ステップ＋送信ボタン | 星4＋コメント欄＋「完了」1つ | 小 |
| J | 理由文 | マスのタップで表示する UI あり | **表示しない。** データは残す。代わりに**ブース説明**を出す | 小 |
| K | 推薦欄 | `CheckInRecommendView` + `/recommendations` API | **削除** | 中 |
| L | コイン | ビンゴが `coins` を計算して返す | **ビンゴはライン数まで。** 換算はガチャ側 | 中 |
| M | 事前アンケート | 位置づけが「必須ではない」 | **6番マスの推薦の唯一の入力。** クリティカルパス | 大 |
| N | 条件属性 | `knowledge_level` / `duration_band` を想定 | **使わない。** 選好一致度＋評価履歴親和度 | 中 |
| O | 推薦の段階 | 単一（あれば DRSA、なければフォールバック） | **3フェーズ**（COVERAGE / SIMILARITY / DRSA） | 大 |
| P | 推薦エンジン | 契約のみ定義、実装なし | **別リポジトリへ切り出す** | 中 |

## 壊れる設計判断（旧仕様の D-xx）

| 旧 | 内容 | 扱い |
|---|---|---|
| 旧 D-1 | ゼロデータで16マスを決めるのを諦める | **維持**（より強化された） |
| 旧 D-2 | 解放条件は実訪問3件。DRSA は比較を要求するため | **失効。** 1回目の解放は実訪問2件で走る。フェーズ設計で受け止める |
| 旧 D-3 | 中央1マスを参加ボーナスとして達成済みで配る | **失効**（[D-1](01-concept/decisions.md)） |
| 旧 D-9 | 評価は3段階 | **失効。** 4段階へ（[D-7](01-concept/decisions.md)） |
| 旧 D-11 | ボーナスブースに訪問しても中央マスは埋まらない | **消滅。** ボーナス自体が無くなった |
| 旧 Q-4 | 参加ボーナスのブース選定ルール | **消滅** |
| 旧 Q-5 | 外周12マスの実験デザイン（位置のランダム化） | **不要。** 開放位置が参加者ごとに異なるため位置効果が構造的に消える |
| 旧 Q-6 | 出展者へのヒアリング | **不要**（[D-12](01-concept/decisions.md)） |

## そのまま使えるもの

- **マスの採番。** 旧実装の 0-15 採番・中央 {5,6,9,10} は議事録の 1-16 採番と一致する
- ライン定義（10ライン）
- チェックイン API の骨格、`pending_rating` の算出規則
- 自己修復の考え方（回数を3回に拡張する）
- 条件付き UPDATE による排他（単位をペアごとに変える）
- `booth_ratings` のスキーマ（`comment` / `scale` / `prompt_context` は既にある）

## 実装順序

1. **事前アンケートのサーバー実装**（[specs/pre-survey](../pre-survey/README.md)）
   — 事前推薦マスの前提
2. **マイグレーション**（アンケート側とまとめて1回で実行）
3. 純関数（ペア判定・ライン判定）と、その単体テスト
4. カード発行・チェックイン・解放
5. 推薦フェーズとフォールバック
6. API の変更（`unlocked_positions` / `coins` 削除 / `/recommendations` 削除）
7. フロント（カード表示・解放演出3回・評価モーダル・推薦欄削除）
8. 運営ダッシュボードの監視項目
9. 実機リハーサルと負荷試験
