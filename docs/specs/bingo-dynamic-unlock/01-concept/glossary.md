# 用語とマス番号

全体の用語は [docs/ubiquitous-language.md](../../../ubiquitous-language.md) が正本。
ここには本機能に固有のものだけを置く。

## マス番号の対応（事故が起きやすいので必ず参照する）

議事録・打ち合わせでは **1〜16 のカレンダー採番**を使う。
コード・DB・API では **0〜15 の行優先採番**を使う。**議事録番号 = コード番号 + 1。**

```
議事録番号（1-16）        コード番号（0-15）
  1  2  3  4               0  1  2  3
  5 [6][7] 8               4 [5][6] 7
  9 [10][11] 12            8 [9][10] 11
 13 14 15 16              12 13 14 15
```

角括弧が中央4マス。議事録の {6, 7, 10, 11} = コードの **{5, 6, 9, 10}**。

**本仕様書は、以降すべてコード番号（0〜15）で記述する。**
議事録を参照するときだけ 1〜16 に読み替える。

## 用語

| 日本語 | コード上の名前 | 定義 |
|---|---|---|
| ビンゴカード | `bingo_card` | 参加者1人につき1枚。16マスからなる |
| マス | `bingo_cell` | カードの1マス。`position` 0〜15 |
| 中央マス | `zone = 'CENTER'` | position {5, 6, 9, 10}。参加者の自由な訪問で埋まる |
| 外周マス | `zone = 'OUTER'` | 中央以外の12マス。推薦で埋まる |
| 事前推薦マス | `source = 'PRESURVEY'` | position 5。事前アンケートから決めた推薦ブースを最初から表示する |
| 中央ペア | — | 達成済みの中央マス2つの組。1組が1本のビンゴ列に対応する |
| 解放 | `unlock` | 中央ペアの成立により、その列の外周マスを見える状態にすること |
| 解放イベント | `card_unlock_event` | 1回の解放。1枚のカードにつき最大3回起きる |
| 見える / 見えない | `is_revealed` | マスの中身（ブース）を参加者に見せてよいか |
| 達成 | `is_achieved` | そのマスのブースにチェックイン済みか |
| 推薦度 | `recommendation_score` | 参加者とブースの組に対する、推薦時点のスコア |
| フェーズ | `phase` | 推薦戦略の段階。`COVERAGE` / `SIMILARITY` / `DRSA` |
