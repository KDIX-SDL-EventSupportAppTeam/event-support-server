# ライン判定

**ビンゴ側が計算するのは成立ライン数までである。コインという言葉を持ち込まない**
（[D-5](../01-concept/decisions.md)）。

## 定義

4×4 の全10ライン（4行 + 4列 + 2対角）。`position` は行優先 0..15。
一覧は [unlock-pairs.md](unlock-pairs.md#全10ライン) を参照。

```ts
// src/lib/bingo/lines.ts（DB を触らない純関数）
export function countCompletedLines(achieved: ReadonlySet<number>): number
```

達成済み position の集合から、成立しているライン数を返す。

## 中央4マスだけではラインは成立しない

中央2×2 {5, 6, 9, 10} は行でも列でも対角でもない。**4マス揃ってもビンゴは1本も成立しない。**
中央完成を特別扱いする処理を書かないこと。

## 最初のラインは4件の訪問で成立する

中央2マス（自由訪問）→ その列の外周2マスが開放 → 外周2マスを訪問、で行または列が完成する。
去年と同じコスト（[D-4](../01-concept/decisions.md)）。

## コインは扱わない

- `calcCoinsEarned()` をこのモジュールから**削除する**
- `MAX_COINS` 定数も削除する
- ビンゴカード API は `coins` を返さず `lines_completed` を返す
- ライン数からコイン枚数への換算は、ガチャ側の責務
  （[specs/gacha-and-award](../../gacha-and-award/README.md)）

## テストで固定すること

- 中央4マスすべて達成でもライン数が 0 であること
- 中央2 + 外周2（同一ライン）で 1 になること
- 16マスすべて達成でライン数が 10 になること
- ライン判定が達成済みの集合だけに依存し、達成した順序に依存しないこと
