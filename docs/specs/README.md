## 読むときの約束

- 各ファイル冒頭の**状態**を必ず見る。「確定」でないものは実装しない
- `09-open-questions/` にあるものは**決まっていない**。勝手に決めて実装しない
- 各機能の `00-must-do.md`（絶対にやることリスト）を実装前に読む

## 書くときの約束

- 決定が変わったら**上書きする**。変更前の記述を残さない（残すなら [archive/](../archive/)）
- 「なぜそうしたか」は [decisions/](../decisions/) に書く。仕様書には結論を書く
- API 契約はこのリポジトリが正本。フロント・推薦エンジンからはリンクで参照させる
