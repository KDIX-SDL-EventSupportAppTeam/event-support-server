# Architecture Decision Records

設計上の重要な判断を短い ADR として残す。  
新規 ADR は **`docs/legacy/adrs/` ではなく本ディレクトリ** に追加する。

## ファイル名

```
NNNN-kebab-case-title.md
```

`NNNN` は 4 桁の連番（例: `0001-use-fastify.md`）。

## テンプレート（目安）

1. タイトル・日付・ステータス（提案 / 承認 / 廃止）
2. コンテキスト（なぜ決める必要があったか）
3. 決定
4. 結果・トレードオフ
