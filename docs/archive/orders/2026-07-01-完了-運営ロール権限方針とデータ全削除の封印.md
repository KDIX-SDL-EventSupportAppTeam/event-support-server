## 背景

manager が「ブース・カテゴリの追加/削除など全ての操作」を行えるようにしたい、
あわせて追加・制限すべき操作の要否を確認したい、という要望。
監査の結果、権限モデルは既に要望どおりで、確認事項2点についてユーザー判断を得た。

## 決定事項（ユーザー確認済み）

1. **manager = 全書き込み操作可（既にそうなっている / 変更不要）**
   - 書き込み系は全て `requireManager`、参照系は `requireStaff`（manager+viewer）。
   - manager は両方を通過するため、ブース/カテゴリ/アンケート設問の作成・更新・削除、
     参加者削除、イベント情報編集などをすべて実行できる。viewer は参照のみ。
2. **スタッフ（運営者）管理は主催者(organizer)のみのまま（現状維持 / 変更不要）**
   - 運営者の追加・削除・ロール変更は `POST /organizer/events/:id/staff`（`requireOrganizer`）。
   - manager による運営者管理は許可しない（manager が別 manager を作れる権限昇格を避ける）。
3. **イベントデータ全削除は封印（無効化）する**
   - 破壊的なため、当面 manager を含め誰も実行できないようにする。
   - 将来は主催者(organizer)専用機能として再設計する（別タスク）。
