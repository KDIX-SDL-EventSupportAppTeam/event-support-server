# ADR 0006 — ビンゴ・ガチャ・アワード投票を初期バックエンドから除外する

**日付:** 2026-05-13  
**ステータス:** 採用

## 背景

旧 Flask バックエンドにはビンゴカード・ガチャコイン・アワード投票の3機能が実装されていた。バックエンドを Fastify に全換装するにあたり、これらの扱いを決定する必要があった。

## 決定

3機能すべてを初期実装の範囲外とする。

| 機能 | 判断 | 理由 |
|------|------|------|
| ビンゴカード | 廃止 | 推薦エンジンと密結合しており、設計書にも存在しない。ゲームシステム自体が今後変更される可能性が高い |
| ガチャコイン | 初期除外（後から追加可） | 現イベントでは不要。コアフローと独立しているため後から追加が容易 |
| アワード投票 | 初期除外（後から追加可） | イベント要件が未確定。コアフローと独立しているため後から追加が容易 |

## 後から追加する際の影響範囲

- **ガチャコイン・アワード投票** はいずれもコアテーブル（`check_ins`・`users` 等）への変更が不要で、独立したテーブルとエンドポイントの追加で実現できる（database.md §10 参照）。
- フロントの `GachaponPage`・`AwardVotePage` は React 側にすでに存在するが、対応する API が未実装のため機能しない状態となる。要件確定後に API 側を追加する。

## 影響

- Canonical DDL（database.md §11）に `award_votes`・`gacha_coins` テーブルは含めない。
- api.md にアワード投票・ガチャのエンドポイントは定義しない。
- `recommender/` のアルゴリズムはビンゴカードの生成ロジックと切り離して設計する。
