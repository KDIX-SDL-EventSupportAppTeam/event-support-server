# バックエンドリプレイス

**日付:** 2026-05-13  
**依頼者:** プロジェクトオーナー  
**影響範囲:** バックエンド（`backend/`）・推薦エンジン（`recommender/`）・DB  
**優先度:** 高

## 概要

旧 Flask バックエンドを廃止し、設計書どおり Node.js + Fastify（TypeScript）＋ MySQL に置き換える。

## 確定した方針

| 項目 | 方針 |
|------|------|
| フレームワーク | Flask → Fastify（TypeScript）全換装。旧コードは削除 |
| DB | MySQL 8 / InnoDB。Canonical DDL（database.md §11）が正 |
| 認証 | JWT（Bearer）。初期はメール＋パスワードのみ。Google OAuth・メール送信は後から |
| ゲーム機能 | ビンゴ・ガチャ・アワード投票は除外。後から追加可能な設計を維持する |
| 推薦 | `recommender/` FastAPI。Strategy パターンで初期は Random。フェーズ自動判定は後から |
| エクスポート | Google Sheets API。イベント終了時にエンドポイントをトリガー |

## 完了条件

- [ ] `backend/` が Fastify（TypeScript）で動作する
- [ ] MySQL に対して Canonical DDL のマイグレーションが動作する
- [ ] api.md に定義されたエンドポイントが実装されている（認証〜推薦・ダッシュボード）
- [ ] `recommender/` が FastAPI で起動し、Random 推薦を返す
- [ ] Fastify から推薦エンジンへの内部通信が動作する
- [ ] Google Sheets エクスポートエンドポイントが動作する
